# ⚡ DMZ Ki Addon

Addon para Dragon Mine Z que añade nuevos ataques de Ki al juego.

## 🚀 Características

- Nuevos ataques de Ki
- Integración con el sistema base de Dragon Mine Z
- Enfoque simple y directo (sin cambios innecesarios al gameplay)


## 📦 Requisitos

- Minecraft 1.20.1
- Minecraft Forge
- Dragon Mine Z (2.0,)

## 🛠 Instalación

1. Instala Forge
2. Instala Dragon Mine Z
3. Coloca el `.jar` del addon en la carpeta `mods`
4. Inicia el juego
